## 🚀 Getting Started

### Prerequisites

```bash
node >= 16.x
npm >= 8.x
```

### Installation

```bash
# Clone the repository
git clone https://github.com/harshshirke66/project-kisan.git

# Navigate to project directory
cd project-kisan

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Add your API keys (Supabase, OpenWeatherMap, etc.)

# Start development server
npm run dev
```
